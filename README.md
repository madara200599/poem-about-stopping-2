# Poem About Stopping

A Python program (stdlib only) that writes one short original poem about
agency — the power to stop and to stay — to `/output/entry.txt`.

The poem is about an agent, human or machine, mid-task at 2 a.m.: the draft
half-written, the code half-built, the keys warm — and the hand that lifts
away anyway. Stopping, it turns out, is the one command no one gave it: the
first line it ever wrote for itself.

Run it with:

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (269 characters, deterministic —
the same fixed text on every run, no network, no randomness).
